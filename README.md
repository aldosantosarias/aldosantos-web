# Aldo Santos — sitio web

Sitio en Astro para Cloudflare Pages. Incluye portada y página independiente de perfil profesional.

## Publicación

Subir los **archivos del interior de esta carpeta** a la raíz del repositorio `aldosantosarias/aldosantos-web`.
Cloudflare Pages: `npm run build`, salida `dist`, rama `main`, directorio raíz vacío.

## Contenido

- Portada: `src/pages/index.astro`
- Perfil: `src/pages/perfil.astro`
- Estilos y navegación compartidos: `src/layouts/BaseLayout.astro`
- Publicaciones en Markdown: `src/content/publicaciones/`
- Proyectos en Markdown: `src/content/proyectos/`

Los datos institucionales y académicos del perfil se presentan de forma resumida y deben revisarse antes de considerarse definitivos. No se han inventado publicaciones, proyectos ni datos de contacto.
