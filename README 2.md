# aldosantos.pe

Sitio profesional de Aldo Santos, construido con Astro y preparado para Cloudflare Pages y Pages CMS.

## Publicación en Cloudflare Pages
1. Conecta este repositorio de GitHub a Cloudflare Pages.
2. Selecciona el framework **Astro**.
3. Build command: `npm run build`.
4. Build output directory: `dist`.
5. Deja el dominio personalizado para una segunda etapa.

## Editar publicaciones
El archivo `.pages.yml` configura Pages CMS. Tras conectar GitHub en https://pagescms.org/, selecciona este repositorio para añadir artículos y proyectos desde el navegador.

## Advertencias
Los textos son borradores sujetos a aprobación. No hay proyectos o publicaciones ficticios precargados. Antes de publicar, confirmar biografía, correo de contacto y documentos autorizados.
